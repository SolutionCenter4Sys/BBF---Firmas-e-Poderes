DECISOES FIXAS (validas em todos os workflows)
1. Repositorio: BBF---Firmas-e-Poderes (branch ProjetoBBF como base; cada OS abre wf-NN-slug).
2. Spec executavel = UI Next.js + src/lib/mocks.ts + docs de pipeline. Nao apagar as telas. Desligar mocks por fatia.
3. Stack alvo: ASP.NET Core 8 + EF Core + Npgsql + PostgreSQL 16 + React/Next.js 14 (D01-A). Sem Dapper, sem SQL Server.
4. Compose local: 4 containers — db (5432), api (8080), worker (sem porta), web (3000). KAAS e servico externo.
5. OCR/transcricao: KAAS jornada testes-firmas-e-poderes. .NET orquestra ingest (action=ingest) e result (action=result).
6. Fuso: America/Sao_Paulo. timestamptz em UTC na persistencia; conversao na borda da API.
7. Portas: db 5432, api 8080, web 3000. Nao usar 8000 (conflito comum) nem expor o worker.
8. Arquivos compose: compose.dev.yaml (so db) e compose.yaml (4 servicos). Nao commitar .env com KAS_API_KEY.
9. Chave KAAS so no Worker/Api (env). Proibido NEXT_PUBLIC_ para a chave.
10. AWS e etapa posterior (WF-22). Nenhuma OS faz terraform/apply.
11. Um branch por item, commit convencional. OS nao escreve no branch da outra.
12. Toda OS de codigo termina com VERIFICACAO executada e saida colada. Sem evidencia = nao concluida.
13. Idioma: Portugues do Brasil (arquivo, tela, Enviando). Nao usar PT-PT.
14. correlationId BBF (corr_uuid) e obrigatorio em toda chamada de pipeline; executionId do KAAS e opcional.
